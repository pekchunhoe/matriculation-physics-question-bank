# Audit before changes

Baseline commit: `fb06375`. Working tree was clean at audit start. Existing architecture: React/Vite frontend, Express API, local SQLite (Node 24), shared Zod validation, KaTeX, local file storage. The existing 30 unit/HTTP and 12 browser tests all passed before edits; typecheck, lint, migration and question-schema checks passed.

Read-only production checks on 7 October 2026: the supplied Vercel root returned HTTP 200 with the matching built frontend; `/api/taxonomy` and `/api/questions` returned HTTP 404. No production writes, uploads, migration execution, or deployment were attempted. This repository has no Vercel API adapter/configuration, hosted database/storage connection, Supabase integration, or authentication. A working durable production backend cannot be inferred from the frontend deployment.

Safe policy chosen: a referenced taxonomy subtree cannot move in place. Major syllabus changes use a new curriculum version and new taxonomy IDs; original questions stay linked to their original IDs. Rename/reorder/retire/restore preserve IDs and require an impact review when questions/history reference the item. Existing historical labels are reconstructed once during migration and explicitly labelled as reconstructed; new snapshots capture exact classification at save. No existing snapshot is rewritten.
